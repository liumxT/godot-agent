# Game Design Document（E11-T02）

## 1. 游戏概念

玩家扮演一名小型冒险者，穿越 Green Hills 关卡，击败巡逻的史莱姆守卫，
收集金币与宝石，抵达终点旗帜。核心体验是「节奏明快的跳跃 + 近战」，
关卡长度控制在 3–5 分钟。

## 2. 目标与动机

- 短期目标：跳过平台、击败敌人、收集金币。
- 中期目标：在生命耗尽前抵达终点。
- 长期动机（Demo 内）：刷新最佳分数。

## 3. 核心体验支柱

| 支柱 | 说明 | 设计手段 |
| --- | --- | --- |
| 清晰控制 | 玩家输入立即得到可预期反馈 | 加速度/跳跃缓冲/土狼时间 |
| 风险回报 | 高台宝石需要冒险 | 浮空平台 + 宝石分值 50 |
| 可读战斗 | 攻击前摇、命中与受伤反馈清楚 | Hitbox 有效帧 + 无敌闪烁 |
| 低门槛 | 首关教学化 | 前 2 屏无敌人，仅平地跳跃 |

## 4. 游戏循环

1. 主菜单 → 开始游戏。
2. 关卡探索：移动、跳跃、攻击、收集。
3. 受伤与恢复：生命 3 点，无敌帧 1 秒。
4. 抵达终点 → 胜利结算 → 记录最佳分数。
5. 生命归零 → 失败结算 → 重试。

## 5. 关卡结构

单关卡 6 个区段，难度单调递增但保留回退空间：

| 区段 | 内容 | 目的 |
| --- | --- | --- |
| TUTORIAL | 平地、低平台 | 教学移动与跳跃 |
| JUMPS | 三段递进高台 | 跳跃精度 |
| TRAPS | 地刺与窄平台 | 风险控制 |
| ENEMY | 两名巡逻敌人 | 战斗教学 |
| COLLECT | 金币弧线与高台宝石 | 收集动机 |
| GOAL | 终点旗帜 | 结算 |

## 6. 难度曲线

- 0–20%：无威胁，建立控制信心。
- 20–50%：平台间距增加，出现首个地刺。
- 50–80%：敌人与环境陷阱组合。
- 80–100%：连续跳跃 + 高台宝石，容错降低但不引入新机制。

## 7. 范围

不在 Demo 内实现：多关卡选择、Boss、技能树、装备、剧情分支。
