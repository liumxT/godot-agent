## 1. 新增

### 1.1 安装器与首次运行向导

- **安装状态机**：覆盖预检查、安装、验证、回滚、卸载全流程；关键项未通过禁止安装。
- **目录隔离**：安装目录与数据目录强制分离，防止数据被覆盖。
- **首次运行向导**：12 步引导完成凭据、模型、项目连接；凭据缺失或模型不可用时阻止继续。
- **插件安装计划**：自动识别 `SKIP / INSTALL / UPGRADE / CONFLICT`，冲突文件不覆盖用户修改。

### 1.2 配置与 Secrets 管理

- **四层配置**：`SYSTEM < USER < PROJECT < SESSION`，受保护键不可被低层覆盖。
- **Secrets 引用**：敏感值必须使用 `cred://` / `secret://` / `keyring://` / `env://` / `${VAR}` 引用，明文被拒绝。
- **脱敏导出**：导出配置时自动脱敏密钥与绝对路径。
- **模型显式选择**：模型不可用直接失败，不静默降级到其他模型。

### 1.3 License 与授权

- **License 状态机**：支持 ACTIVE、GRACE（离线宽限）、EXPIRED、REVOKED、CLOCK_ANOMALY 等状态。
- **Feature Flag**：默认关闭，需显式开启；授权变更写入审计。
- **离线宽限**：在线 License 离线后进入宽限期，过期后自动失效。

### 1.4 更新通道与自动更新

- **三通道**：`DEV` / `BETA` / `STABLE`，默认 `STABLE`。
- **签名校验**：更新清单必须带 HMAC-SHA256 签名与 SHA-256 哈希；签名无效、哈希不符、版本低于当前版本时禁止安装。
- **用户批准**：安装前必须显式批准；批准后清单内容变化会自动失效，需重新批准。

### 1.5 数据库迁移与恢复

- **自动迁移**：升级前强制创建备份，备份路径写入迁移记录。
- **降级阻断**：schema 高于产品支持版本时阻止启动，防止降级写入。
- **失败恢复**：迁移失败进入 `RECOVERY_REQUIRED`，按运维手册恢复。
- **恢复点**：支持数据库、配置、插件、完整恢复；无法确认的外部状态标记为 `UNKNOWN`，需人工核实。

### 1.6 兼容性矩阵与环境诊断

- **平台支持**：Windows x86_64（VERIFIED）、Linux x86_64（PARTIAL）、macOS（UNVERIFIED）。
- **Godot 版本**：4.5.x（VERIFIED）、4.4.x（PARTIAL）、≤ 4.3（UNSUPPORTED）。
- **环境检查**：安装前校验系统、架构、Godot 版本、协议版本、数据库 schema、凭据存储与磁盘空间。
- **UNKNOWN 规则**：未知环境永不自动通过，需人工确认。

### 1.7 安全加固

- **RBAC 权限模型**：产品读动作允许非 Agent 已认证客户端；所有变更动作要求 admin；Agent 一律拒绝。
- **审计日志**：所有产品变更写入 `product_audits`，关联 `client_id` / `session_id`。
- **签名与哈希**：更新与发布候选强制签名校验，签名无效禁止安装。

### 1.8 隐私与数据治理

- **遥测默认关闭**：开启必须显式选择类别（如崩溃报告、使用统计）。
- **上下文预览**：不包含项目源码、资源、绝对路径与密钥。
- **数据删除**：仅影响遥测与诊断记录，不触碰项目文件。
- **支持包脱敏**：导出前需确认，密钥、Token、绝对路径自动脱敏。

### 1.9 诊断与支持包

- **错误目录**：9 个标准错误码，每个错误码关联恢复步骤与文档链接。
- **支持包**：包含产品版本、组件、健康检查、日志摘要与最近审计；默认脱敏，导出需确认。
- **崩溃报告**：默认仅本地保存（`LOCAL_ONLY`），不会自动上传。

### 1.10 文档与 Onboarding

- **[用户指南](../user-guide.md)**：安装、首次运行、日常使用、升级/回滚/卸载、平台支持等级、隐私与故障排查。
- **[开发者指南](../developer-guide.md)**：模块边界、版本与契约、API 摘要、状态机、扩展点、迁移与测试。
- **[运维手册](../../04-operations/runbooks.md)**：安装/更新/迁移失败、恢复、数据库损坏、凭据、模型、安全事件、支持包、长期运行、发布与下线。

### 1.11 产品发布流水线

- **发布候选**：必须满足版本域正确、7 类证据齐全、签名 `SIGNED`、SBOM 可用。
- **审批门禁**：审批要求候选处于可审批状态；发布要求 `APPROVED` 且签名与证据仍有效。
- **发布脚本**：`build_product.py` 生成产品/组件/契约/兼容性清单、SBOM 与校验和；`--check` 模式用于 CI 门禁。
- **API 稳定级别**：契约登记 10 项，未知或超版本契约为 `UNKNOWN`。

## 5. 升级说明

### 5.1 数据库迁移

- **自动执行**：启动时自动从 `000032` 迁移到 `000033`，升级前自动创建备份。
- **备份位置**：默认 `<数据目录>/backups/`，备份路径写入迁移记录。
- **手动迁移**：如需手动执行，使用后端打包产物的 `--migrate` 入口。

### 5.2 配置变更

- 无新增或重命名配置变量。
- 敏感值必须使用引用格式（`cred://` 等），现有明文配置会在保存时被拒绝。

### 5.3 密钥变更

- 无需重新配置密钥。
- 更新签名密钥：当前使用内置 HMAC 密钥；公共分发时需升级为非对称签名。

### 5.4 回滚方式

1. **安装回滚**：在安装界面选择回滚到上一个可用版本，用户数据保留。
2. **数据库回滚**：从迁移前备份恢复，使用匹配 schema 的产品版本启动。
3. **插件回滚**：插件安装计划会识别版本冲突，冲突文件不覆盖用户修改。
4. **恢复点**：支持数据库、配置、插件与完整恢复；无法确认的外部状态需人工核实。

## 8. 下载与安装

### 8.1 系统要求

- **操作系统**：Windows 10/11 x86_64（VERIFIED）、Linux x86_64（PARTIAL）
- **Godot**：4.4+（推荐 4.5.1）
- **磁盘**：至少 2 GB 可用空间
- **内存**：建议 8 GB 以上

### 8.2 安装步骤

1. 关闭正在运行的 Godot 编辑器。
2. 运行对应平台安装包。
3. 选择安装目录（与数据目录分离）。
4. 完成首次运行向导（12 步）。
5. 在 Godot 中启用插件并连接后端。

详细步骤见 [用户指南](../user-guide.md)。
